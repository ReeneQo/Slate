# infrastructure/

Технические интеграции, отделённые от доменных модулей: `prisma`, `redis`, `storage`.

- `PrismaModule` оборачивает клиент из `@slate/database` и предоставляет его репозиториям.
- Доменные модули зависят от инфраструктуры, но не наоборот.
