# @slate/database

Единый источник схемы данных: **Prisma schema** + сгенерированный клиент.
Этот пакет — единственное место, где живёт ORM; репозитории `apps/api` импортируют клиент отсюда.

## Статус

Заглушка. Prisma **намеренно не установлен** на этапе 1.

На этапе 2 здесь появятся:

```
packages/database/
├── prisma/
│   ├── schema.prisma     # модели
│   └── migrations/       # миграции
└── src/                  # реэкспорт PrismaClient + типов
```

PostgreSQL, миграции и клиент настраиваются в задаче бэкенда/БД.
